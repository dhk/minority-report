# Synthesis: Custom Apps for read-only reporting migrations

The research supports a narrow, defensible recommendation: teams doing
read-only, non-technical reporting can reasonably evaluate Custom Apps as a
Lightdash replacement today. The evidence does not support a broader claim
that Custom Apps replaces a governed BI tool for teams that need row-level
access control or a shared metrics layer.

This should be revisited after Supersimple's GA release, since one model
surfaced an undocumented embedding API that could change the access-control
picture if it ships stable.
